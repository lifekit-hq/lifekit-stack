# MEMORY.md - a pointer, not a store

Long-term memory lives in the vault, `~/memory/`: one memory store for every
agent and tool. This file holds no facts, and every deploy rewrites it.

- Who the owner is and how to work with them: read `~/memory/CORE.md` first.
- Where a fact lives: `~/memory/index.md`. A fact many pages restate has one
  owning page, listed in `~/memory/bin/subjects.txt` (the career target, for
  example, is on `~/memory/domains/career.md`).
- Finding something: `memory_search` covers the vault pages.
- Recording a durable fact or decision: it goes to its owning vault page, per
  your AGENTS.md rule for vault writes (`~/memory/README.md` is the contract),
  never into this file.
- Daily notes: `memory/YYYY-MM-DD.md` in this workspace.
